# Rocket Shift

Планировщик дня для **Windows**: один **% дня** по факту времени, виджет на рабочем столе, закрытие дня и сравнение с вчера. Не todo-лист.

**Сайт:** [rocketshift.ru](https://rocketshift.ru)

## Скачать (Windows)

**Требования:** Windows 10/11. Node.js, npm и другие инструменты **не нужны**.

1. Скачайте установщик: [Rocket-Shift-Setup-1.0.2.exe](https://github.com/BUNDY888/ROCKET-SHIFT/releases/download/v1.0.2/Rocket-Shift-Setup-1.0.2.exe)
2. Запустите → «Далее» → готово.
3. Ярлык на рабочем столе, данные локально в `%APPDATA%\RocketShift\`.

Бета, бесплатно. Аккаунт и интернет для работы приложения не требуются.

## Возможности

- Временные и фиксированные задачи с расчётом общего процента (может быть > 100%)
- Цветовые зоны: красный / оранжевый / зелёный / фиолетовый
- Почасовая гистограмма на главном экране
- Мини-виджет «всегда поверх» с % дня
- Закрытие дня: настроение, streak, сравнение с вчера
- Макро-цели на месяцы и годы (часы из задач)
- Чеклисты внутри временных задач (не влияют на % дня)
- Настройки: иконка виджета, автозапуск Windows

## Для разработчиков

Стек: **Electron + React + TypeScript + Vite**.

### Требования

- Node.js 18+
- npm 9+

### Клонирование и запуск

```bash
git clone https://github.com/BUNDY888/ROCKET-SHIFT.git
cd ROCKET-SHIFT
npm install
npm run dev
```

Запускается Vite и Electron: главное окно, виджет и иконка в трее.

Если `dev` не поднимает Electron автоматически:

```bash
npm start
```

### Сборка установщика

```bash
npm run build:installer
```

Готовый файл: `release/Rocket-Shift-Setup-1.0.2.exe`

Только распакованная папка (без установщика):

```bash
npm run build:dir
```

### Структура проекта

```
electron/          — главный процесс (окна, IPC, tray, JSON-хранилище)
src/               — React UI
  lib/             — расчёт процентов, форматирование
  views/           — главное окно, виджет
```

### Логика процентов

**Временная задача:** вклад = `(факт / план) × (план / Σпланов) × 100`.

**Фиксированная:** при отметке «Выполнено» добавляется вес (%).

**Гистограмма:** вклад временной задачи равномерно делится по часам интервала `[начало, конец)`; фиксированные — в час выполнения.

### IPC (основное)

| Канал | Назначение |
|--------|------------|
| `state:get` / `state:update` | Чтение и рассылка состояния |
| `day:save` / `day:reset` | Сохранение и сброс дня |
| `day:close` | Закрытие дня |
| `settings:save` | Настройки + автозапуск |
| `widget:drag` | Перетаскивание виджета |
| `window:show-main` | Открыть главное окно по клику на виджет |
