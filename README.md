# Rocket Shift

Десктопное приложение для планирования дня (Windows, macOS, Linux) на **Electron + React + Vite**.

## Возможности

- Временные и фиксированные задачи с расчётом общего процента (может быть > 100%)
- Цветовые зоны: красный / оранжевый / зелёный / фиолетовый
- Почасовая гистограмма под процентом на главном экране (Recharts)
- Мини-виджет «всегда поверх» с обновлением через IPC
- Настройки: иконка виджета, автозапуск Windows
- Данные в `%APPDATA%\RocketShift\data.json` (Windows)

## Требования

- Node.js 18+ (установлен в `C:\Program Files\nodejs`)
- npm 9+

**Важно для Windows:** после установки Node.js добавьте в PATH папку `C:\Program Files\nodejs` *выше* других путей. Иначе в терминале Cursor может подхватываться встроенный `node` без `npm`. Быстрый запуск: ярлык **Rocket Shift** на рабочем столе или `run-dev.cmd`. Пересоздать ярлык: `npm run shortcut`.

## Запуск в режиме разработки

```bash
npm run dev
```

Запускается Vite и Electron: главное окно, виджет и иконка в трее.

Альтернатива (если `dev` не поднимает Electron автоматически):

```bash
npm start
```

## Сборка установщика (раздать другим)

Один файл для Windows — мастер установки с ярлыком на рабочем столе:

```bash
npm run build:installer
```

Готовый установщик:

`release/Rocket-Shift-Setup-1.0.0.exe`

Пользователю: скачать → запустить → «Далее» → готово. Данные сохраняются в `%APPDATA%\\RocketShift\\`.

Только распакованная папка (без установщика, для себя):

```bash
npm run build:dir
```

Артефакты — в папке `release/`.

## Структура проекта

```
electron/          — главный процесс (окна, IPC, tray, JSON-хранилище)
src/               — React UI
  lib/calculations.ts — логика процентов и гистограммы
  views/           — главное окно, виджет
```

## IPC

| Канал | Назначение |
|--------|------------|
| `state:get` / `state:update` | Чтение и рассылка состояния |
| `day:save` / `day:reset` | Сохранение и сброс дня |
| `settings:save` | Настройки + автозапуск |
| `widget:drag` | Перетаскивание виджета |
| `window:show-main` | Открыть главное окно по клику на виджет |

## Логика процентов

**Временная задача:** вклад = `(факт / план) × (план / Σпланов) × 100`.

**Фиксированная:** при отметке «Выполнено» добавляется вес (%).

**Гистограмма:** вклад временной задачи равномерно делится по часам интервала `[начало, конец)`; фиксированные — в час выполнения.
